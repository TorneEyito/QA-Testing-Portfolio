# 🧪 E-Commerce Website Testing - Manual QA Project 

This repository contains manual test cases for an e-commerce website.

## 📦 What’s Included

The project covers several key areas of the website:

- 🔐 **Login Functionality**
- 🛒 **Shopping Cart**
- 🔍 **Search Feature**
- 👤 **Edit Profile**
- 💳 **Checkout Process**

Each feature is tested for expected functionality, edge cases, and error handling.


## 🔧 Tools Used

- Microsoft Excel
- Markdown editor
- Manual website testing
- Chrome Mobile Browser

This is a manual testing practice project created as part of my journey to become a QA Software Tester. More features and updates will be added as I continue learning.
