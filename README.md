This repository contains my Manual Testing project on an e-commerce website

What is inside 

TestScenarios/     → Module-based test scenario descriptions TestCases/         → Documented manual test cases with status tracking
BugReports/        → Individual bug reports with clear reproduction steps

README.md            → Overview of the project (this file)

Documents Overview
1. Test Scenarios
Located in:TestScenarios.md
Includes high-level workflows that outline how key features are expected to behave.

2. Test Cases
Located in:TestCases.md
Contains step-by-step test cases linked to the scenarios above, each with test steps, input data, expected results, and test status.

3. Bug Reports
Located in:Bug_Report
Each file includes:
Summary of the issue
Steps to reproduce
Expected vs. actual results
Test environment details

Purpose
This project demonstrates my ability to:

Analyze features and write clear test scenarios

Identify bugs and document them with professional standards

It is intended to showcase my understanding of QA documentation and help me grow toward a professional testing role.

Tools Used
